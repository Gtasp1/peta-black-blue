# Pokémon Black & Blue (PETA Parody) – Offline Archive

This is an offline mirror of the browser game **Pokémon Black & Blue** originally published by PETA at:

https://games.peta.org/pokemon-black-and-white-parody/

## Why this archive exists
PETA has occasionally taken down or changed their interactive content. This repository preserves a playable copy of the HTML5 (Phaser) version of the game for historical / archival purposes.

## How to play
1. Clone or download this repository.
2. Serve the folder with any static web server (required because of browser security for local files), for example:

```bash
# Python 3
python3 -m http.server 8000

# or Node.js
npx serve .
```

3. Open http://localhost:8000 in your browser.

Alternatively you can use the original Flash (.swf) version archived on the Internet Archive:

https://archive.org/details/flasharchive-pokemon_blackwhite
